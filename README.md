# Financial-Performance-Dashboard---Power-BI
## Présentation du projet

Ce projet consiste en la création d'un tableau de bord financier interactif développé avec Power BI.

L'objectif est d'analyser la performance commerciale et financière d'une entreprise à travers plusieurs indicateurs clés de performance (KPIs), notamment les ventes, le profit, les produits les plus performants et les résultats par pays.

Le tableau de bord permet aux décideurs d'obtenir une vision claire de l'activité et de prendre des décisions basées sur les données.

## Jeu de données

Le projet utilise le Financial Sample Dataset de Microsoft.

Ce jeu de données contient des informations relatives à :

- La segmentation des clients
- Les produits vendus
- Les pays
- Les quantités vendues
- Les ventes
- Les remises
- Les coûts (COGS)
- Les profits
- Les dates de transaction

Les données ont été nettoyées, transformées et modélisées dans Power BI avant la création des visualisations.
